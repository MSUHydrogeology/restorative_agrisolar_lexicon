# Contributing

This is a draft design language, not a finished standard. The most useful contributions are:

**Project accounts.** A description of a real array, working or not, tests the vocabulary better
than anything else. The [Describe a project](https://github.com/MSUHydrogeology/restorative_agrisolar_lexicon/issues/new?template=describe-a-project.yml)
issue form asks what the ground was before, what changed, who runs it, what was promised, what was
measured, and what did not work.

**Counterexamples.** The document makes at least one falsifiable claim — that *idled-land sparing*
(S4) is largely unavailable at utility scale (A5), because siting there is governed by contiguous
land assembly. The sharp version: a utility-scale S4 project assembled from *scattered* marginal
remnants on ordinary farmland, rather than the uniformly pre-disturbed ground (brightfields) the
standing exception already allows. A documented project of that kind is valuable. Please include
what fraction of the footprint is genuinely marginal ground.

**Terms in use that are missing.** If practitioners in your region use a term this lexicon lacks,
open an issue with the term, a working definition, and where you have seen it used.

**Citation corrections.** The `Sources` page separates verified from unverified entries. Moving an
entry from the second list to the first, with a checked citation, is a real contribution.

**Calibration.** The scale bands are indicative for the US Midwest. Regional calibrations —
different capacity thresholds, absent zones, different siting regimes — are welcome as additions
rather than replacements.

## What this document tries not to do

It describes and compares; it tries not to prescribe. The documented failure mode of form-based
codes is rigidity, and the analogous risk here is a lexicon that hardens into a scorecard and
locks in ground-cover prescriptions. Proposals that add scoring, thresholds, or compliance
criteria will be considered, but against that concern.

## Process

Open an issue for discussion, or a pull request for text. Substantive changes to the three
structural devices — the transect, the farming axis, the pressure set — should start as
issues.
